# 残差を対数領域で足す — 複素 Σ-Product Unit の多層化

⚠️ AI-assisted; verify. / 生成AI使用・要検証

実装: `csigma_deep.py`(`DeepCSPU`)、実験: `physics/deep_test.py`、結果: `physics/results/deep_test.txt`、
経緯と数値: `physics/LEARNING.md` の「Depth」節。

## 1. 普通の残差はなぜ足し算か

ResNet の x_{ℓ+1} = x_ℓ + f(x_ℓ) は、「何もしない層 = f ≡ 0」が恒等写像になる形である。足し算の単位元が 0 だから、
f を 0 から始めれば深くしても最初は素通しになる。残差の本質はこの「単位元から始める」ことであり、「足す」こと自体は
加法の世界の都合にすぎない。

## 2. Product Unit の世界は掛け算

Σ-PU は y = Σ a·exp(W·Log x) で、内部の自然な演算は x^W、つまり掛け算とべき乗である。この世界の単位元は 0 でなく
**1** で、「何もしない」は x に 1 を掛けること。したがって残差は

    x_{ℓ+1} = x_ℓ · g(x_ℓ),   g ≡ 1 で恒等

という**乗法的残差**になる。g を「1 から始めて動かす」ものと考えると g = exp(Δ) と書くのが素直で、Δ = 0 が恒等。

## 3. 対数を取ると足し算に戻る

L = Log x とおくと上の式は

    L_{ℓ+1} = L_ℓ + Δ_ℓ

である。掛け算の残差は対数座標では普通の足し算の残差になる。これが「残差を対数領域で足す」の意味であり、Δ_ℓ を
作る部品として Σ-PU がそのまま使える:

    Δ_ℓ = Σ_u a_{ℓ,u} · exp(W_{ℓ,u} · L_ℓ)        (出力次元 = 特徴数 F: 各特徴の対数座標をいくら動かすか)

係数 a を 0 から始めれば Δ = 0 で全ブロックが恒等。これは 4 チャネル(a = a⁺ − a⁻、両チャネル等しい)の初期状態そのもの
である(ResNet の「最終層をゼロ初期化」が構成から出る)。

## 4. なぜこれが多層化の問題を解くか

素朴に層を積むと、層の出力 y(複素数)を次の層でまた Log しなければならない。y は 0 の近くにも負の実軸にも行くので、
毎層で分岐切断・2π の巻き・Log₀(0) が現れる。対数ストリームでは **Log₀ は入口で一度だけ**(全域算術: 0 入力は
Log₀ 0 = 0 で積から抜け、ε は旗つきの境界値)。以後はストリーム L に Δ を足すだけで、exp(W·L) は ℂ 全体で正則、切断も
0 も出ない。L の虚部は**ほどけた位相**として溜まるので、位相が何周しても情報は失われない。

## 5. z = 1 + i·y/s との関係

「出力 y を 1 のまわりに埋め直して Log を取る」形は、Log(1 + δ) ≈ δ なので**一次近似の残差**である。右半平面に
留まるので安全だが、位相が atan で飽和し、chirp のように位相が伸びる情報は運べない。対数ストリームはその近似を厳密に
したもので、2 層の目標(chirp 位相 → べき則)で 3〜4 桁の差が出た(`physics/LEARNING.md` の表)。

## 6. 値に戻すと何をしているか

    x_D = x_0 · exp(Δ_1) · exp(Δ_2) · … · exp(Δ_D)

各層が「掛け算の補正係数」を 1 つずつ掛けていく。基準状態(= 1; 入力を基準値との比にする無次元化がここで効く)からの
乗法的な補正の積み重ねで、head の y = Σ c·exp(V·L_D) は最後にストリームのべきを読む。

## 7. 対数で深さが潰れる

head が 1 ユニットなら y = c·exp(V·L_D) なので

    Log y = Log c + V·L_D = Log c + V·(L_0 + Σ_ℓ Δ_ℓ)

ブロックが 1 つなら Δ_1 = a·e^{W·L_0} で、Log y(位相は標本の経路に沿って unwrap)は「定数 + 線形 + 指数 1 項」の形に
なり、未知数は W だけ(他は線形)。41×41 の格子で篩い Gauss–Newton で仕上げると、Adam が 3 000 歩で 1e-3〜1e-6 に
止まった目標で W = 0.5, V = −0.8, a = 0.5i, c = 1.5−0.5i を機械精度(残差 4e-31)で回収した。教訓はペンシルと同じで、
模型の代数(積の指数は指数の和)がどんな歩幅則より効く。

ブロックが 2 つ以上だと Δ_2 = Σ a_2·e^{W_2·(L_0+Δ_1)} が入れ子になり、完全には線形化できない。位相の unwrap は標本が
経路(掃引)に沿って並ぶことを要する(ペンシルが格子を要するのと同じ)。ここが次の問い。

## 8. 実験の要約(`physics/deep_test.py`, Adam 3 000 歩, 6 seed, held-out 相対損失の中央値)
